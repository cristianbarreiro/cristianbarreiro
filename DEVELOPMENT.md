# Web demo

This repository includes a small Vite app for experimenting with `lottie-web`. The GitHub profile README remains the repository's primary published content; GitHub README rendering does not execute JavaScript.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The sample animation is stored at `public/animations/technology-orbit.json` and is loaded by `src/main.js`.

To create a production build, run `npm run build`. To preview that build locally, run `npm run preview`.
